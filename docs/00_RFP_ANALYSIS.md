# RFP 원문 분석 (제안요청서 2026.10, 「지능형 무역투자 플랫폼 구축」)

- 출처 파일: `04fd8a2a-…제안요청서….hwpx` → `seed/rfp_requirements.json` (150건 자동 추출)
- 사업기간 계약 후 ~ 2028.09.30(약 21개월), 사업비 20,690,000,000원(VAT 포함, 3차 장기계속)
- 추진과제는 **8개**(상담매칭 · 홈페이지 통합 · 고객상담 데이터 · 해외정보 · 개인정보보호 · AI수출비서 · 통합 데이터 저장소 · 고객데이터 통합)

## 지시서 v3.0 과의 정합성 조정
| 항목 | 지시서 v3.0 | RFP 원문 | MVP 반영 |
|---|---|---|---|
| 추진과제 수 | 7대 | 8개 | 8개로 정정, 개인정보보호(마스킹·차단)를 독립 모듈로 표시 |
| 채널 통합 | 무역투자24 + 투자채널 | 12개 사이트 중 8개 → 2채널 (무투24 ← 6개 사이트, IK&옴부즈만 ← 2개) | 메뉴·RFP Coverage에 6+2 통합 서비스 노출 |
| RAG 도메인 | 8종 | 시장·규제·바이어·마케팅·물류·지원사업·상담FAQ | 10개 컬렉션(위 7 + 전시·투자·일반) |
| RAG 옵션 | 검색모드 | 10개 이상 On/Off, Lexical/Semantic/Hybrid 시뮬레이션, A/B | RAG Manager에 15개 옵션 + 시뮬레이터 |
| 성능 | 체감 | 3초 이내, 3초 초과 시 사전 경고 | 전역 slow-op 경고 + 서버 처리시간 측정 |
| 다국어 | KO/EN | IK는 국·영·중·일 | KO/EN 전체, IK 채널 zh/ja 확장 키 제공 |

## 핵심 원문 요구와 구현 위치 (발췌)
- SFR-004 Header + Quick menu로 어느 화면에서든 이동, 시안 3종 → 홈 레이아웃 3종 선택(`?v=a|b|c`)
- SFR-005 고객 그룹별 메인 구성, 수출준비/초보/유망/중견 필터, 성장단계·산업·지역별 특화사업
- SFR-015 상담요약: 화자분리·STT → 항목 자동추출 → **상담원 수정·승인 후 상담일지 등록**, 신뢰도 낮으면 수동 작성
- SFR-017 상담 이관(대상·사유), 예약콜/콜백, 변경 이력
- SFR-021 에이전트: 시장탐색 / 타겟국가 동향 / 마케팅·영업준비 / 바이어탐색 / 계약·협상(HITL)
- SFR-025 Multi-RAG: Query Decomposition, Multi-Hop(HS코드), Reranker 필수, Text-to-SQL, 권한별 지식 제한
- SFR-026 Tool Use(위젯형/URL스키마형), 4종 Memory, API 인증·로깅·유량제어
- SFR-027 스트리밍, 별점·오류신고, 프롬프트 저장, 내보내기, 개인정보 필터, 범위 밖 질의 대응, 모바일
- SFR-031/032/036 30분 타임테이블(현지시간), 자동매칭 조건, 알림 메일/SMS
- SFR-052/053 해시뉴스·교정교열 Agent (전/후 비교, 팩트체크, 통계)
- SFR-057/059 가명처리·동적 비식별, Data Lineage, Data Drift
- SFR-061 Open API (JSON/XML 동시 제공)
- PER-002/005 3초 응답 · 3초 초과 사전 경고 / QUR-005 AI 품질지표(Tool 성공률, NDCG, 환각률, 토큰비용)
