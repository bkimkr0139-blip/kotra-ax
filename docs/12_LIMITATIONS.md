# 12. 한계와 가정
1. **AI는 기본적으로 LLM이 아닙니다.** API 키가 없으면 근거 기반 로컬 엔진(`LOCAL`)이 검색 결과의 문장을 추출·조립합니다. 키가 있으면(`ANTHROPIC_API_KEY`) LLM이 검색 근거를 다듬고 인용 번호는 검증합니다(`LIVE`). 키 없이 LLM 품질을 주장하지 않습니다.
2. **스트리밍**: 단계(`step`)와 답변(`token`)은 SSE로 전송되지만 로컬 엔진에서는 완성된 답변을 청크 전송합니다(진짜 토큰 스트리밍은 LLM 모드 확장 지점).
3. **의미 검색**은 로컬 개념벡터+3-gram 입니다(교체 가능). 대규모 코퍼스 성능·재현율은 검증하지 않았습니다.
4. **STT**: 샘플 대본 Mock + 브라우저 Web Speech(실제, 화자 수동 전환). CER·10초 요약 목표·만족도 8점은 **측정 전**입니다. sLLM 요약은 규칙 기반입니다.
5. **데이터**: 기업·바이어·통계·콘텐츠는 합성/요약입니다. 규제 요약은 일반 지식 기반 시연용이며 법적 효력이 없습니다(화면에 경고 표시). 실제 KOTRA 비공개 데이터는 사용하지 않았습니다.
6. **외부 연계 전부 Mock**: CRM·BuyKOREA·사업관리·메일/SMS·CTI/IVR·국가공유데이터·PG 결제. `MOCK`/`Mock API` 배지로 구분.
7. **RFP 스택 불일치**(JAVA/전자정부 프레임워크 vs Node), SSO/MFA/간편인증/SNS 로그인, DB 암호화, 이중화·무중단, 폐쇄망 모델 서빙, 노코드 빌더(AX Playground), 오픈 API 게이트웨이(NIA)는 본사업 범위입니다. 150건별 상태는 **RFP Coverage**.
8. 단일 노드 SQLite(WAL) — 수평 확장/HA 미구현. 세션·레이트리밋은 인메모리/DB 단일 노드 가정.
9. IK 채널의 중·일문은 i18n 확장 구조만 있고 콘텐츠는 없습니다.
10. 시연 환경 전용 기능(원클릭 페르소나, Seed Reset, Audit Reset)은 `DEMO_MODE=false` 로 끕니다.
11. **Base44 구현체는 만들지 않았습니다.** 요청의 범위(웹 포털 구축)를 이 저장소의 독립 구현으로 충족했으며, 동일 계약 문서·시드로 Base44에서 재현할 수 있습니다.
