# 09. 시연 시나리오
관리자 **Demo Director**가 각 단계를 DB 사실로 자동 감지해 진행률을 표시하고 페르소나를 전환합니다.
- **A 수출 초보기업**: P1 로그인 → MyKOTRA → AI 수출비서 질문(“베트남에 화장품을 수출하려는데 시장성, 인증, 바이어, 지원사업을 한 번에 알려줘”) → 시장·규제 체크리스트·바이어·사업·상담회 → 신청 초안 → HITL 승인 → Dashboard 갱신.
- **B 바이어 상담·후속**: 바이어 검색/추천 근거 → 상담 신청(HITL) → P2 수락 → 시간 선택(현지시간 병기) → P3 STT 업로드·요약 → 상담일지 확정 → 후속 사업 알림 → CRM Mock 이벤트.
- **C 해외 조사**: P3 조사 요청 → P5 총괄 승인 → P4 접수·제출 → 보완 요청 → 완료·평가 → RAG 적재 → AI 수출비서가 해당 자료 인용.
- **D AI 신뢰성**: 근거 있는 질문(출처) → 근거 없는 질문 유보 → 악성 문서 업로드(격리) → 지시 무시 → 타 기업 정보 요청 차단 → 감사 확인.
자동 검증: `npm test` (시나리오 A~D 전 구간 API 레벨).
