# 05. API 계약 (자동 생성)

지시서 §25 의 의미 계약을 유지합니다. 인증은 세션 쿠키(`kt_sid`, HttpOnly, SameSite=Lax, HTTPS 시 Secure). 오류 형식: `{ "error": { "code", "message", "extra?" } }`.

## AI Chat 응답

```json
{ "answer": "...", "sections": [], "sources": [], "suggested_actions": [], "tool_runs": [], "artifact": null, "abstained": false, "blocked": null, "trace_id": "RUN-0001", "provenance": "LOCAL|LIVE", "latency_ms": 0 }
```
`POST /api/ai/chat?stream=1` 은 SSE(`step`/`token`/`final`/`error`)를 반환합니다.
